# ANABIO.SIS — 3D-движок для 3dfx Voodoo и SoundBlaster Pro 2 под DOS

Игровой 3D-движок для графического ускорителя **3dfx Voodoo 1**, работающий под управлением **MS-DOS**. Использует оригинальный **3dfx Glide SDK** для аппаратного рендеринга треугольников с текстурами, W-buffer и антиалиасингом. Поддерживается звуковые карты **Sound Blaster Pro 2 или совместимые**. В качестве центрального процессора ожидается что-нибудь вроде **Intel Pentium 150-200 MHz**. Движок всё ещё в процессе разработки. Разработка ведётся преимущественно на русском (я русским владею лучше, чем английским), но со временем постараюсь перевести комментарии на английский.

## Возможности

- **Аппаратный 3D-рендеринг** через 3dfx Glide SDK 2.43
- **W-buffer** (аппаратный буфер глубины Voodoo, вместо Z-buffer)
- **Антиалиасинг** треугольников и линий (AA)
- **Загрузка текстур** из файлов `.3df` собственный формат 3dfx (утилита texus.exe)
- **Загрузка моделей** из файлов `.obj` с нормалями и UV-координатами
- **Фрустум-клиппинг** — отсечение треугольников за пределами камеры
- **Камера на кватернионах** — вращение без gimbal lock
- **Спрайтовый шрифт** для вывода текста поверх 3D-сцены
- **Быстрая математика** — LUT-таблицы для sin/cos
- **Поддержка до 3 TMU (теоретически)** (текстурных модулей Voodoo)
- **Тестирование текстурной памяти** TMU на переполнение

## Архитектура

Проект состоит из модульных компонентов:

| Модуль            | Назначение                                              |
|-------------------|---------------------------------------------------------|
| `main.c`          | Главный цикл, инициализация Glide, обработка ввода      |
| `camera.c/.h`     | Камера, кватернионы, матрица View, обработка фрустума   |
| `mesh.c/.h`       | Загружаем модели (.obj), Frustum-cliping, отрисовка меша|
| `matrix.c/.h`     | Матричные операции 4×4 (Model, View, Projection)        |
| `primitiv.c/.h`   | Базовые примитивы (куб для тестов)                      |
| `texture.c/.h`    | Загрузка текстур .3df в TMU-память                      |
| `text.c/.h`       | Спрайтовый шрифт, вывод текста/FPS                      |
| `fastmath.c/.h`   | LUT-таблицы sin/cos, кватернионы                        |
| `keyboard.c/.h`   | Опрос клавиатуры через прерывания                       |
| `timer.c/.h`      | PIT-таймер с повышенной частотой (64×)                  |
| `file.c/.h`       | Утилиты работы с файлами                                |
| `object.c/.h`     | Система игровых объектов (заготовка)                    |

### Пайплайн рендеринга
[Один кадр] 
-> grBufferClear() очистка текущего буфера 
-> UpdateView() обновление матрицы камеры 
-> DrawMesh() рисуем меши 
-> -> ApplyMatrix() применяем матрицу Model View Projection на все вершины мешей 
-> -> DropTriangleByFrustum() отбрасываем невидимые за кадром треугольники 
-> -> grDrawTriangle() отрисовка треугольников железом 3dfx Voodoo 
-> DrawText() вывод текста 
-> grBufferSwap() меняем буферы местами

## Управление

| Клавиша                 | Действие                                       |
|-------------------------|------------------------------------------------|
| **W/A/S/D/Q/E**         | Перемещение камеры (вперёд/влево/назад/вправо) |

### Настройка окружения

Устанавливаем Dosbox-X.

Рекомендуемые настройки для 3dfx Voodoo 1 в dosbox-x.conf:

[voodoo]
voodoo_card   = software
voodoo_maxmem = false
glide         = false
lfb           = full_noaux
splash        = false

Нужно сделать какую-то папку на вашем ПК основным каталогом для Dosbox-X.
Пусть для примера это будет (замените [user_name] на ваш вариант):
C:\Users\[user_name]\DOS
Тогда все последующие папки будут относительно неё дочерними.
Потом в dosbox-x.conf в разделе [autoexec] пишем:

[autoexec]
MOUNT c C:\Users\[user_name]\DOS
C:
cd C:\PROJECTS\ANABIO.SIS
REM COMPILE.BAT
REM MAIN.EXE

Рвздел [cpu] в dosbox-x.conf тоже нуждается в редактировании.

[cpu]
cycles = max

Создайте папку C:\Users\[user_name]\DOS\PROJECTS
Создайте папку C:\Users\[user_name]\DOS\PROJECTS\ANABIO.SIS
Скопируйте *.c/*.h/*.txt/COMPILE.BAT файлы проекта 
в C:\Users\[user_name]\DOS\PROJECTS\ANABIO.SIS

Теперь работаем внутри Dosbox-X.
Тут для удобства можно поставить Norton Commander или Volkov Commander.
Просто закиньте нужные программы в С:\NC или C:\VC и 
работайте дальше через них.
Установите Open Watcom 2.0 beta для DOS (по умолчанию в C:\WATCOM).
Распакуйте Glide SDK 2.43 в папку GLIDE243 с сохранением структуры папок.

Должна получиться следующая структура папок и файлов
C:\Users\[user_name]\DOS\   (настоящее местонахождение)
C:\                         (в Dosbox-X)
└── GLIDE243\
    ├── Src\Sst1\include\   *.h файлы
    └── Lib\Dos\Stack       *.lib файлы
└── PROJECTS\
    └── ANABIO.SIS\          *.c\*.h\*.* файлы этого проекта
        └── TEXTURES\        *.3df текстуры
        └── MODELS\          *.obj модели
        └── COMPILE.BAT      bat-файл для сборки
└── WATCOM\
    └── H\                   *.h файлы
    
### Компиляция

Откройте командную строку DOS и выполните:

COMPILE.BAT

Результат: MAIN.EXE

##  Загрузка текстур

### Формат 3df
Поддерживается собственный формат 3dfx.
В комплекте с Glide SDK 2.43 идёт утилита TEXUS
(находится в \GLIDE243\Bin\Dos).
На вход она принимает только TGA-файлы.
Я написал простой батник (\TEXTURES\TEXUS1.BAT),
который без сжатия конвертирует TGA в 3DF.
Исполняется в Dosbox-X.

C:\GLIDE243\BIN\DOS\TEXUS.EXE -rn -mn -dn -t rgb565 -o .3df %1

Когда мне нужно создать новую текстуру,
я сохраняю её в \TEXTURES в формате TGA,
потом исполняю в этой папке TEXUS1.BAT SAMPLE.TGA.
В папке должен появиться SAMPLE.3DF,
который уже можно грузить в самом движке.

## Загрузка моделей

### Формат Wavefront OBJ
Поддерживается базовый формат .obj:

Вершина v 1.0 0.0 0.0
Тексельная координата vt 0.0 1.0
Нормаль vn 0.0 0.0 1.0
Грань (с текстурами и нормалями) f 1/1/1 2/2/2 3/3/3

### Ограничения
Только треугольники (f v/vt/vn v/vt/vn v/vt/vn)
Квады и полигоны не поддерживаются
Материалы (.mtl) не загружаются
Максимум: 512 вершин, 512 треугольников
