Шпаргалка по текстурной развёртке

1. Подготовка модели
Открыть модель
Перейти в Edit Mode и сделать UV-развёртку
Выйти в Object Mode

2. Создание материала
Создать новый материал
В Shader Editor поставить Emission
Добавить ноду Image Texture
Подключить Color → Base Color
В Image Texture нажать New и создать изображение размера 256×256
Interpolation поставить на Closest (для пиксельного вида)

3. Рисование
Переключиться в режим Texture Paint
В Texture slots выбрать созданное изображение
Рисовать прямо по модели в 3D-вьюпорте

4. Сохранение текстуры
В окне Image Editor убедиться, что открыто именно то изображение, на котором рисовал
Меню Image → Save As…
Сохранить в формате TGA

5. Финальная проверка
Сохранить файл Blender (.blend)
При необходимости экспортировать модель (WaveFront OBJ)
